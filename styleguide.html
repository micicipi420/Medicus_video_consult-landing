Scroll-Edge Fade

CSS mask-image градиент для плавного затухания контента на границах.

scroll-fade-top

Этот контент затухает сверху. Класс .scroll-fade-top добавляет градиент mask-image.

Используется на границах прокручиваемых областей для визуального разделения.

Размер затухания: 80px (настраивается через --scroll-fade-size).

scroll-fade-bottom

Этот контент затухает снизу. Класс .scroll-fade-bottom добавляет градиент mask-image.

Используется на границах прокручиваемых областей для визуального разделения.

Размер затухания: 80px (настраивается через --scroll-fade-size).
