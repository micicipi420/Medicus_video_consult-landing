Иерархия стекла

3 уровня: nav (легчайшее) < regular (стандарт) < clear (оверлей). Плюс текстура fluted.

Level 1: liquid-nav

Навигация, тулбары. Минимальный blur, без внешней тени.

Nav-weight glass. Самое лёгкое и прозрачное стекло для навигации.

.liquid-nav .squircle-lg — blur 16px, alpha 0.28

Level 2: liquid-regular

Карточки, контейнеры. Стандартный blur и тень.

Regular-weight glass. Рабочая лошадка — карточки, формы, блоки.

.liquid-regular .squircle-lg — blur 24px, alpha 0.42

Level 3: liquid-clear

Модалки, лайтбоксы. Максимальная прозрачность + dimming.

Clear-weight glass. Самое прозрачное стекло с затемняющим слоем.

.liquid-clear .squircle-lg — blur 20px, alpha 0.18 + dim

Текстура: liquid-fluted

Декоративные панели. Вертикальные рёбра (рифлёное стекло).

Fluted glass. Рифлёная текстура поверх стандартного стекла.

.liquid-fluted .squircle-lg — repeating-linear-gradient stripes

Scroll-Edge Fade

CSS mask-image градиент для плавного затухания контента на границах.

scroll-fade-top

Этот контент затухает сверху. Класс .scroll-fade-top добавляет градиент mask-image.

Используется на границах прокручиваемых областей для визуального разделения.

Размер затухания: 80px (настраивается через --scroll-fade-size).

scroll-fade-bottom

Этот контент затухает снизу. Класс .scroll-fade-bottom добавляет градиент mask-image.

Используется на границах прокручиваемых областей для визуального разделения.

Размер затухания: 80px (настраивается через --scroll-fade-size).
