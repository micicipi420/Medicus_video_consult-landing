**Contrast Ratio Computation (5 glass elements)**

Compute WCAG contrast ratios analytically. The formula is:

`--liquid-bg` = `color-mix(in oklch, oklch(100% 0 0) 55%, transparent)` = white at 55% alpha  
On a worst-case page background of `#F5F5F5` (off-white), the composite is:  
`composite = 0.55 * white + 0.45 * #F5F5F5 = ~rgb(250, 250, 250)` — luminance ~0.955

Body text color `--mu-text-900` = `#1B212C`. Calculate its relative luminance:
R=27, G=33, B=44 — linearize — luminance ~0.015

Contrast ratio = (0.955 + 0.05) / (0.015 + 0.05) = 1.005 / 0.065 ~= **15.5:1** — far exceeds AA 4.5:1.

On a worst-case background of dark blue (`#0A1628`, Phase 74 target):
Dark bg luminance ~0.006  
`--liquid-bg` dark = `color-mix(in oklch, oklch(22% 0.02 260) 55%, transparent)`  
= navy at 55% alpha on dark bg: composite ~= `rgb(25, 30, 48)` — luminance ~0.009  
Text color in dark mode = white `#FFFFFF` — luminance = 1.0  
Contrast = (1.0 + 0.05) / (0.009 + 0.05) = 1.05 / 0.059 ~= **17.8:1** — exceeds AAA.

Document the 5 spot-check elements:
1. `.liquid-regular` card (body text on glass) — light mode composite
2. `.liquid-nav` header text — light mode
3. `.liquid-card` on index page — light mode
4. `.liquid-fluted` variant — light mode
5. `.liquid-clear` used in social proof — light mode
