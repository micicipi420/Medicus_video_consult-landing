# Phase 1 -- UI Design Contract

> Visual and interaction contract for migrating Redesign/ (React + Tailwind + Framer Motion) to vanilla HTML/CSS/JS. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (vanilla CSS custom properties) |
| Preset | not applicable |
| Component library | none -- hand-coded HTML/CSS |
| Icon library | Lucide SVG (inline `<svg>` paths, no JS runtime) |
| Body font | SF Pro Display, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif |
| Heading font | SF Pro Rounded, SF Pro Display, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif |

**Source:** CONTEXT.md decisions -- SF Pro Display (body) / SF Pro Rounded (headings), inline Lucide SVGs.

**Font fallback note:** SF Pro Display/Rounded are Apple system fonts available only on macOS/iOS. On Windows/Android/Linux the stack falls through to system-ui / Segoe UI / Roboto. This is acceptable -- the redesign already uses this exact fallback chain.

---

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| --space-1 | 4px (0.25rem) | Inline icon gaps, micro padding |
| --space-2 | 8px (0.5rem) | Compact element spacing, badge padding |
| --space-3 | 12px (0.75rem) | Inner card padding (image inset), form field gaps |
| --space-4 | 16px (1rem) | Default element spacing, py on sections |
| --space-5 | 20px (1.25rem) | Badge horizontal padding, button padding-x |
| --space-6 | 24px (1.5rem) | Card content padding, section vertical gaps |
| --space-8 | 32px (2rem) | Major content gaps, CTA padding-x |
| --space-10 | 40px (2.5rem) | Section headings to content |
| --space-12 | 48px (3rem) | Section top/bottom padding (mobile) |
| --space-16 | 64px (4rem) | Section top/bottom padding (desktop) |
| --space-20 | 80px (5rem) | Page-level spacing, hero pt on desktop |

Exceptions:
- Touch targets: minimum 44px (11 spacing units) for all interactive elements per WCAG 2.2 Target Size
- Hero section top padding: 128px (32 * 4) on mobile, 160px on desktop -- accounts for floating header + breathing room

## Animation Contract

### Entrance Animations (Framer Motion -> vanilla CSS + JS)

| Pattern | CSS Properties | Trigger |
|---------|---------------|---------|
| Fade up | opacity: 0 -> 1, translateY(20-50px -> 0) | IntersectionObserver (once, threshold 0.2-0.5) |
| Fade left/right | opacity: 0 -> 1, translateX(+/-30-50px -> 0) | IntersectionObserver (once) |
| Scale in | opacity: 0 -> 1, scale(0.95 -> 1) | IntersectionObserver (once) |
| Spring entrance | opacity: 0 -> 1, translateY(-100px -> 0) | Page load (header only) |
| Stagger | Each card delays by 100-200ms (CSS transition-delay or animation-delay) | Per-card IntersectionObserver |

### Hover Animations

| Element | Transform | Transition |
|---------|-----------|------------|
| CTA button (primary) | scale(1.02) | 200ms ease |
| CTA button (active/tap) | scale(0.98) | 100ms ease |
| Glass card | translateY(-2px) | 500ms ease |
| Guide card | translateY(-8px) | 500ms ease |
| Icon container | scale(1.1) rotate(3-6deg) | 500ms ease |
| Image in card | scale(1.05) | 700ms ease |
| Nav link | color change to --mu-blue | 200ms ease |

### Continuous Animations

| Element | Animation | Duration | Notes |
|---------|-----------|----------|-------|
| Mesh blob 1 | translate + scale | 15s, infinite, ease-in-out | Fixed background, z-0 |
| Mesh blob 2 | translate + scale | 18s, infinite, ease-in-out | Fixed background, z-0 |
| Mesh blob 3 | translate + scale | 22s, infinite, ease-in-out | Fixed background, z-0 |
| CTA section glow | scale(1-1.3) + opacity(0.3-0.6) | 8s, infinite, ease-in-out | Inside CTA wrapper only |
| Counter (stats) | Number count-up 0 -> target | 2000ms, 60 steps, triggered once | JS setInterval, IntersectionObserver |

### prefers-reduced-motion Guard

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

All entrance animations: elements render at final position immediately. Counter shows final number without counting. Mesh blobs static (no animation). Hovers remain functional but without transform transitions.
