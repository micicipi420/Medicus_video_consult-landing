  <files>css/styles.css</files>
  <read_first>css/styles.css, .planning/phases/10-visual-design-enhancement/10-CONTEXT.md</read_first>
  <action>
In css/styles.css, modify the hero section styles (around line 348-393):

1. **Gradient background (per D-01):** Replace `background-color: var(--color-light)` on `.hero` with:
   ```
   background: linear-gradient(135deg, rgba(56, 198, 244, 0.08) 0%, rgba(53, 182, 120, 0.06) 100%), var(--color-light);
   ```
   This creates a subtle blue-to-teal gradient at low opacity over the light base.

2. **Dot-grid pattern overlay (per D-04):** Add a `::before` pseudo-element on `.hero` for the dot-grid:
   ```css
   .hero {
     position: relative;
     overflow: hidden;
   }
   .hero::before {
     content: '';
     position: absolute;
     inset: 0;
     background-image: radial-gradient(circle, var(--color-dark) 1px, transparent 1px);
     background-size: 24px 24px;
     opacity: 0.03;
     pointer-events: none;
     z-index: 0;
   }
   .hero__container {
     position: relative;
     z-index: 1;
   }
   ```

3. **2-column layout on desktop (per D-03):** Add flexbox layout to `.hero__container` for 768px+:
   ```css
   @media (min-width: 768px) {
     .hero__container {
       display: flex;
       align-items: center;
       gap: var(--space-5);
     }
     .hero__content {
       flex: 1 1 60%;
       max-width: none;
     }
     .hero__illustration {
       flex: 0 0 35%;
       display: flex;
       align-items: center;
       justify-content: center;
     }
   }
   ```

4. **Hide illustration on mobile (per D-03):**
   ```css
   .hero__illustration {
     display: none;
   }
   ```
   The `display: flex` in the 768px media query overrides this.

5. **Illustration SVG styling:**
   ```css
   .hero__illustration svg {
     width: 100%;
     max-width: 320px;
     height: auto;
   }
   ```
