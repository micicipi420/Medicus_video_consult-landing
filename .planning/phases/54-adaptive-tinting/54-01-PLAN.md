Modify the `background` property on ALL glass material classes to composite the tint color as an additional gradient layer beneath the existing --liquid-bg.

Per VFEX-01: tinting is achieved via background-gradient composite, NOT mix-blend-mode.

The technique: use a multi-value `background` with a linear-gradient of the tint color stacked under the existing solid --liquid-bg layer. The tint color uses the inherited --liquid-tint-* properties:

For `.liquid-regular` (Section 1), replace:
```css
background: var(--liquid-bg);
```
with:
```css
background:
  linear-gradient(
    to bottom,
    var(--liquid-bg),
    var(--liquid-bg)
  ),
  linear-gradient(
    to bottom,
    hsla(var(--liquid-tint-h), var(--liquid-tint-s), var(--liquid-tint-l), var(--liquid-tint-a)),
    hsla(var(--liquid-tint-h), var(--liquid-tint-s), var(--liquid-tint-l), var(--liquid-tint-a))
  );
```

The first gradient is the existing glass surface (liquid-bg). The second gradient is the tint layer underneath. Because liquid-bg is semi-transparent (0.42 light / 0.45 dark), the tint bleeds through subtly.
