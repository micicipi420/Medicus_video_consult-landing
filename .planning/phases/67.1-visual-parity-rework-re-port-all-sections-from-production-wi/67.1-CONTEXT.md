<decisions>
## Implementation Decisions

### Glass vs Production Styling
- Keep glass classes on existing sections but apply production's flat hex backgrounds as the base layer; glass classes add subtle depth on top. Per project memory rule: NEVER replace glass classes with plain bg-white/shadow
- Match production solid buttons: Primary solid #35B678 green, Secondary dark-bordered outline #18212C. Remove glass gradient button styles
- Cards: production flat style (white bg, border, shadow) but keep glass squircle radius for modern feel
- Header: replace glass material blur on scroll with production's simple box-shadow approach

### Page Scope
- Port all 3 missing service pages: consultations, treatment-abroad, checkup
- Extract content from production HTML files verbatim — copy all text, section structure, layout patterns
- Contacts page: revert to production layout (remove CoordinatorCard, TrustBadges redesign; match production's simpler lead-form pattern)
- Footer: match production navy #1A365D (replace current #1B212C)

### Animation & Typography
- Match production typography exactly: 18px base font, clamp() headings (H1: 40-56px, H2: 28-44px, H3: 22-32px)
- Keep existing Framer Motion scroll/entrance animations — they don't interfere with layout and add polish over production
- Mobile menu: match production hamburger behavior (same items, order, slide-in pattern)
- Sticky bar: match production styling exactly (background color, phone number display, CTA button style)

### Claude's Discretion
- Component decomposition for the 3 new service pages
- CSS custom property naming for production tokens
- Tailwind config structure for production type scale
- Order of implementation across sections

</decisions>
