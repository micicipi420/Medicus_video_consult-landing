## Component Details

### ServiceHero (Server Component)
- Props: eyebrow, title (ReactNode), subtitle, primaryCta, secondaryCta, trustLine, illustration, variant
- Layout: 2-column grid (content + illustration) matching production `.hero` structure
- Typography: `clamp(2.5rem,5vw,3.5rem)` H1, `1.25rem` subtitle with `max-w-[640px]`
- Buttons: `btn-primary btn-hero` / `btn-outline btn-hero` from Plan 01 utility classes
- Decorative: 2 gradient orbs (default) or 3 (abroad/checkup variant)

### SocialProof (Server Component)
- Props: items array of `{ number, label }`
- Layout: `bg-[#1A365D]` navy bar, flex row on desktop, column on mobile
- Typography: `2.5rem` bold white numbers with `tabular-nums`, `1.125rem` labels at `white/85`

### FAQ (Client Component)
- Props: items array of `{ question, answer: ReactNode }`, heading (default: "Частые вопросы"), id
- Accordion: `useState<Set<number>>` for multi-open toggle
- Accessibility: `aria-expanded` on buttons, native button keyboard support
- Animation: chevron SVG rotates 180deg with `motion-safe:transition-transform duration-200`
- Styling: `border border-black/[0.06] rounded-2xl`, `max-w-[800px]` centered list

### LeadFormSection (Server Component wrapper)
- Props: heading, subtext (ReactNode), trustItems, privacyText, id
- Layout: `grid-cols-1 md:grid-cols-2` with trust items left, form right
- Form wrapper: white bg, `border-black/[0.08]`, `rounded-2xl`, `shadow-[0_2px_8px_rgba(0,0,0,0.08)]`
- Imports and renders existing `ContactForm` client component
- Trust items: green checkmark SVG (`stroke="#047857"`) with `text-[#4A4E5C]`

### Contacts Page Simplification
- Removed: ContactsHero, CoordinatorCard, ContactMethodGrid, TrustBadges imports
- Added: simple hero section + LeadFormSection with contacts-specific copy
- Preserved: all SEO metadata (title, description, Open Graph, canonical)
- Old contact components NOT deleted (available for future use if needed)

## Decisions Made

1. **FAQ multi-open**: Used `Set<number>` instead of single-index state to allow multiple FAQ items open simultaneously -- matches common UX expectations
2. **ServiceHero orb count via variant**: The `variant` prop controls decorative orb count rather than a separate prop, keeping the API surface small
3. **LeadFormSection delegates to ContactForm**: No form logic duplication -- LeadFormSection is purely a layout wrapper around the existing ContactForm client component
4. **Contacts page old components preserved**: Per plan instruction, old ContactsHero/CoordinatorCard/ContactMethodGrid/TrustBadges files were NOT deleted
