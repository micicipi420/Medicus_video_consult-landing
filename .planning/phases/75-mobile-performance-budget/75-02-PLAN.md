<objective>
Apply content-visibility: auto to below-fold sections in production HTML pages (PERF-03) so the browser skips initial layout and paint for off-screen content, reducing rendering work on first load for mid-range Android devices.

Purpose: Each page (index, checkup, consultations, treatment-abroad) has 5-10 sections. Without content-visibility, the browser lays out ALL sections at parse time even though only the first 1-2 are visible. On a mid-range Android at 375px, laying out a 4000px-tall page costs significant CPU time before the first frame. content-visibility: auto skips off-screen sections until they approach the viewport, cutting initial layout cost by 60-70%.

Output: A single appended block in css/styles.css targeting all identified below-fold section classes with content-visibility: auto and appropriate contain-intrinsic-size values.
</objective>

For contain-intrinsic-size: Use measured approximate heights. These are estimates — the browser uses them to allocate scrollbar space. Values use the format `auto Npx` where `auto` means the browser remembers actual size after first render (Chrome 105+). For older Chrome, the fallback Npx is used.

   contain-intrinsic-size format: `auto Xpx` where:
   - `auto` = remember real size after first paint (Chrome 105+)
   - `Xpx` = fallback estimate for initial layout (used for scrollbar sizing)

   Approximate height estimates (mobile, 375px viewport):
   - .hub-services:       ~1200px (service cards grid)
   - .hub-guide:          ~600px
