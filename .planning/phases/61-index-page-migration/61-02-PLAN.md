**ContactForm.tsx** -- Client Component ("use client"):

```
'use client';

import { useState, useRef, type FormEvent, type ChangeEvent } from 'react';
```

State:
- `formState: 'idle' | 'submitting' | 'success'` via useState
- `errors: Record<string, string>` via useState (keys: name, phone, interest)
- `loadTimeRef` via useRef(Date.now()) -- for spam timing check
- Form field values: `name`, `phone`, `interest`, `description`, `website` (honeypot) -- all string state

**Phone mask function** `formatPhone(value: string): string`:
- Extract digits only: `value.replace(/\D/g, '')`
- Ensure starts with 7: if not, prepend 7
- Cap at 11 digits
- Format progressively:
  - `+7` (always)
  - `+7 (XXX` when 2-4 digits
  - `+7 (XXX) ` when 4+ digits
  - `+7 (XXX) XXX` when 5-7 digits
  - `+7 (XXX) XXX-XX` when 8-9 digits
  - `+7 (XXX) XXX-XX-XX` when 10-11 digits

**Validation function** `validate(): Record<string, string>`:
- name: trim, if length < 2 -> error "Введите ваше имя"
- phone: extract digits, if not 11 digits starting with 7 -> error "Введите корректный номер телефона"
- interest: if empty string -> error "Выберите направление"
- Return errors object (empty = valid)

**handleSubmit(e: FormEvent)**:
- e.preventDefault()
- Check honeypot: if `website` is non-empty, silently set success (don't submit)
- Check timing: if `Date.now() - loadTimeRef.current < 3000`, silently set success
- Run validate(), if errors -> setErrors and return
- Set formState to 'success' (Phase 65 will add actual API call here)
