**Step 4: Ensure `<style>` blocks cover JS-toggled states**
The `<style>` block in each HTML `<head>` must include:
```css
/* Header scroll state */
.header--scrolled {
  background: rgba(255,255,255,0.5);
  backdrop-filter: blur(60px) saturate(180%);
  -webkit-backdrop-filter: blur(60px) saturate(180%);
  padding-top: 0.75rem;
  padding-bottom: 0.75rem;
}
/* Mobile menu toggle */
.mobile-menu-overlay { display: none; }
.mobile-menu-overlay.is-open { display: block; }
/* Form validation */
.is-invalid { border-color: var(--mu-accent-red) !important; }
/* FAQ accordion */
.faq__answer { max-height: 0; overflow: hidden; transition: max-height 0.3s ease; }
.faq__item.is-open .faq__answer { max-height: 500px; }
/* Form success/error messages */
.form__success, .form__error { display: none; }
.form__success.is-visible, .form__error.is-visible { display: block; }
.form__field-error { display: none; color: var(--mu-accent-red); font-size: 0.875rem; margin-top: 0.25rem; }
.is-invalid + .form__field-error,
.is-invalid ~ .form__field-error { display: block; }
```

Verify this block exists in ALL 5 HTML files' `<head>` sections.
