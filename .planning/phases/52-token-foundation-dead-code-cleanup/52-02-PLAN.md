<objective>
Remove all .liquid-card-wrap wrapper divs from HTML across all 7 pages and delete the CSS class definition.

Purpose: The .liquid-card-wrap wrapper was created in v4.0 as a shadow-bearing outer element for squircle glass cards (mask-image clips box-shadow). Since then, box-shadow has been moved to the glass classes themselves (.liquid-regular, .liquid-card), making the wrapper a structural no-op. Removing 146 wrapper divs eliminates dead HTML weight and simplifies the DOM tree for subsequent v5.0 phases.

Output: All 7 HTML pages without liquid-card-wrap divs, CSS class removed, documentation updated.
</objective>
