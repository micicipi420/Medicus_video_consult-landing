**Part A: Extend initMouseSpecular() in js/main.js**

Replace the current `.liquid-card`-only selector with a combined selector targeting ALL glass surface classes:

```js
function initMouseSpecular() {
  if (window.matchMedia && window.matchMedia('(pointer: coarse)').matches) return;
  if (window.matchMedia && window.matchMedia('(prefers-reduced-motion: reduce)').matches) return;

  var SELECTOR = '.liquid-card, .liquid-regular, .liquid-nav, .liquid-clear, .liquid-fluted, .stats-glass';

  document.addEventListener('mousemove', function(e) {
    var els = document.querySelectorAll(SELECTOR);
    for (var i = 0; i < els.length; i++) {
      var rect = els[i].getBoundingClientRect();
      // Calculate percentage including OUTSIDE the element (negative/over-100 values)
      // This creates the "specular follows cursor direction even outside" effect (VFEX-02)
      var x = ((e.clientX - rect.left) / rect.width * 100);
      var y = ((e.clientY - rect.top) / rect.height * 100);
      els[i].style.setProperty('--mouse-x', x + '%');
      els[i].style.setProperty('--mouse-y', y + '%');
    }
  });
}
```

The percentage values naturally extend outside 0-100% when the cursor is outside the element. This satisfies VFEX-02: "specular follows cursor OUTSIDE the card (near but not on it)." The radial-gradient `at var(--mouse-x) var(--mouse-y)` positions the highlight center beyond the element boundary, creating a soft glow at the nearest edge.
