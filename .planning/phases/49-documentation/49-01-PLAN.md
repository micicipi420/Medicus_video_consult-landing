## 4. Shadow-Wrap Idiom
Explanation paragraph: mask-image clips box-shadow. Use wrapper for shadow + inner element for mask.

Three copy-paste HTML examples (verbatim from squircles.css header):

Card example:
```html
<div class="liquid-card-wrap">
  <article class="squircle-lg liquid-card">
    <!-- card content -->
  </article>
</div>
```

Button example:
```html
<div class="btn-shadow-wrap">
  <button class="squircle-md px-6 py-3 text-white">
    Submit
  </button>
</div>
```

No-wrap cases:
- Inset shadows: safe inside mask (form example)
- No shadow: badges, chips, pills (span example)

## 5. Anti-Patterns

Numbered list with clear "NEVER do X because Y" format. Consolidate from both squircles.css and liquid-glass.css headers:

1. NEVER apply box-shadow AND mask-image to the same element. Shadow clips to mask silhouette. Use shadow-wrap.
2. NEVER apply border to a squircle element. Borders clip by mask. Use `box-shadow: inset 0 0 0 1px <color>`.
3. NEVER apply squircle to rotating elements. mask-image distorts during CSS rotate(). Keep border-radius.
4. NEVER use will-change: backdrop-filter on static cards. Wastes GPU memory.
5. NEVER nest glass inside glass. Double backdrop-filter compounds blur and kills readability.
6. NEVER use shimmer on non-hero elements. Max 1 shimmer per viewport for 45+ audience.
7. NEVER use border on masked glass. Use inset box-shadow (rim lighting tokens handle this).

## 6. Russian Typography Rules

### 6.1 nbsp Binding
Explanation: bind subject+verb pairs with `&amp;nbsp;` to prevent line breaks. All prepositions (в, на, с, к, у, о, за, по, из, до, от, при, для, без, про) bind to the next word.

### 6.2 Orphan Prevention
Rule: first line before a break must have 2+ words AND 10+ chars. Chain nbsp to push break later.

### 6.3 whitespace-nowrap
For compound units like "за 1-2 дня" that must never break: use `<span class="whitespace-nowrap">`.

### 6.4 text-wrap: balance
NEVER use text-wrap: balance. Count must remain zero across all pages (migration gate checks this).

### 7.2 Adding a New Page
Step-by-step checklist:
1. Create the HTML file at project root
2. Add BUILD:vars with CTA_HREF, CTA_LABEL, CURRENT_PAGE
3. Add all 5 partial marker pairs (BUILD:header...etc)
4. Add page to Makefile PAGES list
5. Add page to scripts/build-pages.sh DEFAULT_PAGES
6. Add CURRENT_PAGE case to build-pages.sh if new nav item
7. Run `make build` to splice partials

### 7.3 Tailwind Build
Command: `make build` runs tailwindcss CLI + splicer. Source scanning: `@source '../../*.html'` in tailwind.css.
