   - Line 2: `-webkit-backdrop-filter: ...` (Safari hardcoded fallback)
   - Line 3: `-webkit-backdrop-filter: ...` (Safari with var() values)

   The CURRENT production order is:
   ```css
   -webkit-backdrop-filter: blur(24px) saturate(180%) brightness(108%); /* hardcoded */
   -webkit-backdrop-filter: blur(var(...)) saturate(var(...)) brightness(var(...)); /* var */
   backdrop-filter: blur(var(...)) saturate(var(...)) brightness(var(...)); /* standard */
   ```

   The REQUIRED Next.js order (Turbopack bug #78302 fix) is:
   ```css
   backdrop-filter: blur(var(...)) saturate(var(...)) brightness(var(...)); /* standard FIRST */
   -webkit-backdrop-filter: blur(24px) saturate(180%) brightness(108%); /* Safari hardcoded */
   -webkit-backdrop-filter: blur(var(...)) saturate(var(...)) brightness(var(...)); /* Safari var */
   ```

   Classes that need this fix (search for `backdrop-filter` and reorder):
   - `.liquid-regular` (Section 1)
   - `.liquid-nav` (Section 1.1)
   - `.liquid-clear` (Section 1.2)
   - `.liquid-fluted` (Section 1.3)
   - `.liquid-card` (Section 2)
   - `.liquid-btn-secondary` (Section 3)
   - `.stats-glass` (Section 4)

   - Line 1: `backdrop-filter: url(#...) blur(...) saturate(...) brightness(...);`
   - Line 2: `-webkit-backdrop-filter: url(#...) blur(...) saturate(...) brightness(...);`

   For the reduced-motion section (Section 13), the override uses simple `blur(8px)` -- apply the same standard-first order:
   ```css
   backdrop-filter: blur(8px);
   -webkit-backdrop-filter: blur(8px);
   ```
