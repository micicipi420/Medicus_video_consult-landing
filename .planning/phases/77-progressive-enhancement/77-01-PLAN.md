The block must be structured as:

```css
/* ==========================================================================
   PHASE 77: Progressive Enhancement — Scroll-Driven Animations (PERF-04)
   @supports gate: only Chrome 115+ and future engines see this.
   Firefox/Safari continue using the IntersectionObserver + .is-visible path.
   ========================================================================== */

@supports (animation-timeline: scroll()) {

  /* Keyframe: fade in + slide up, driven by element scroll position */
  @keyframes scroll-fade-in {
    from {
      opacity: 0;
      transform: translateY(20px);
    }
    to {
      opacity: 1;
      transform: translateY(0);
    }
  }

  /* Override the IO-based transition with scroll-driven animation.
     animation-range: entry 0% entry 30% means the animation plays
     as the element scrolls from 0% to 30% of its entry into the viewport.
     fill: both ensures opacity:0 before entry and opacity:1 after. */
  .animate-on-scroll {
    opacity: 0;
    transform: translateY(20px);
    /* Remove the JS-transition approach — CSS drives this now */
    transition: none;
    animation: scroll-fade-in linear both;
    animation-timeline: view();
    animation-range: entry 0% entry 30%;
  }

  /* Glass variant: same scroll-driven fade but also scales from 0.98 */
  @keyframes scroll-fade-in--glass {
    from {
      opacity: 0;
      transform: translateY(20px) scale(0.98);
    }
    to {
      opacity: 1;
      transform: translateY(0) scale(1);
    }
  }

  .animate-on-scroll.animate-on-scroll--glass {
    animation-name: scroll-fade-in--glass;
  }

  /* .is-visible added by JS IO is now a no-op — the scroll-driven
     animation already resolved opacity/transform. Keep the rule to
     avoid any specificity fights but it changes nothing visible. */
  .animate-on-scroll.is-visible {
    /* intentionally empty — scroll-driven animation handles final state */
  }

  /* Stagger: shift animation-range start per child so later children
     enter slightly later along the scroll axis.
     Each step delays the entry start by 5% of the scroll range. */
  .stagger-children > .animate-on-scroll:nth-child(1) { animation-range: entry 0%  entry 30%; }
  .stagger-children > .animate-on-scroll:nth-child(2) { animation-range: entry 5%  entry 35%; }
  .stagger-children > .animate-on-scroll:nth-child(3) { animation-range: entry 10% entry 40%; }
  .stagger-children > .animate-on-scroll:nth-child(4) { animation-range: entry 15% entry 45%; }
  .stagger-children > .animate-on-scroll:nth-child(5) { animation-range: entry 20% entry 50%; }
  .stagger-children > .animate-on-scroll:nth-child(6) { animation-range: entry 25% entry 55%; }
  .stagger-children > .animate-on-scroll:nth-child(7) { animation-range: entry 30% entry 60%; }

  /* prefers-reduced-motion: disable scroll-driven animations entirely.
     Elements render at their final visible state immediately. */
  @media (prefers-reduced-motion: reduce) {
    .animate-on-scroll,
    .animate-on-scroll.animate-on-scroll--glass {
      animation: none;
      opacity: 1;
      transform: none;
    }
  }

} /* end @supports (animation-timeline: scroll()) */
```

Do NOT change any existing rules above this block. Do NOT touch the existing `.animate-on-scroll` rules at lines 1516-1548 or the reduced-motion overrides at lines 1636-1650 — the IO path must stay intact for Firefox/Safari.

```css
  /* ==========================================================================
     PHASE 77: Scroll Progress Bar (PERF-05)
     Renders as a 3px colored bar at the bottom edge of the site header.
     Grows from left (0%) to right (100%) as the page scrolls root to end.
     Completely absent on non-supporting browsers — no DOM change needed.
     ========================================================================== */

  .site-header {
    /* Required so ::after positions relative to the header */
    position: relative;
    /* Ensure the progress bar doesn't overflow outside the header visually */
    overflow: visible;
  }

  .site-header::after {
    content: '';
    position: absolute;
    bottom: 0;
    left: 0;
    height: 3px;
    /* Start at 0 width — animation-timeline drives it to 100% */
    width: 100%;
    /* Brand green progress indicator */
    background: linear-gradient(
      to right,
      var(--color-cta) var(--scroll-progress, 0%),
      transparent var(--scroll-progress, 0%)
    );
    /* Scale from scaleX(0) to scaleX(1) using transform-origin: left */
    transform: scaleX(0);
    transform-origin: left center;
    /* Scroll-driven: tied to root scroll, 0 = page top, 100% = page bottom */
    animation: scroll-progress-bar linear both;
    animation-timeline: scroll(root);
  }

  @keyframes scroll-progress-bar {
    from { transform: scaleX(0); }
    to   { transform: scaleX(1); }
  }

  /* prefers-reduced-motion: hide the progress bar entirely */
  @media (prefers-reduced-motion: reduce) {
    .site-header::after {
      display: none;
    }
  }
```
