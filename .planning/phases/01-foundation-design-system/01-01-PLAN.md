
    2. Download Inter variable WOFF2 font files (cyrillic + latin subsets):
       - Source: Fontsource npm package OR google-webfonts-helper OR GitHub releases (rsms/inter)
       - Download the variable weight WOFF2 files for both latin and cyrillic subsets
       - Place as: `assets/fonts/inter-latin-wght-normal.woff2` and `assets/fonts/inter-cyrillic-wght-normal.woff2`
       - If Fontsource: `npm pack @fontsource-variable/inter` then extract woff2 files from the package
       - If direct download fails, use curl from a CDN like `https://cdn.jsdelivr.net/fontsource/fonts/inter:vf@latest/cyrillic-wght-normal.woff2`

    3. Download Manrope variable WOFF2 font files (cyrillic + latin subsets):
       - Same approach as Inter
       - Place as: `assets/fonts/manrope-latin-wght-normal.woff2` and `assets/fonts/manrope-cyrillic-wght-normal.woff2`
       - If Fontsource: `npm pack @fontsource-variable/manrope` then extract woff2 files

    4. Create `index.html` with this exact content:
       ```html
       <!DOCTYPE html>
       <html lang="ru">
       <head>
         <meta charset="UTF-8">
         <meta name="viewport" content="width=device-width, initial-scale=1.0">

         <!-- Preload critical fonts (cyrillic first -- primary content language) -->
         <link rel="preload" href="assets/fonts/inter-cyrillic-wght-normal.woff2"
               as="font" type="font/woff2" crossorigin>
         <link rel="preload" href="assets/fonts/manrope-cyrillic-wght-normal.woff2"
               as="font" type="font/woff2" crossorigin>

         <title>MedicusUnion KZ -- Консультации с европейскими врачами</title>
         <link rel="stylesheet" href="css/styles.css">
       </head>
       <body>
         <!-- Sections will be added in phases 2-5 -->
         <!-- JS will be added in phases 6-7 -->
       </body>
       </html>
       ```

    IMPORTANT: The `crossorigin` attribute on font preloads is mandatory even for self-hosted fonts (per research pitfall 3). Do NOT omit it.
    IMPORTANT: Font files must be actual WOFF2 binaries, not empty placeholders. Verify each file is >10KB after download.
  </action>
