**File 1: next/src/hooks/use-scrolled.ts**

"use client" hook. Returns boolean `isScrolled` based on `window.scrollY > threshold` (default 10). Implementation:
- useState(false) for isScrolled
- useEffect with scroll listener using rAF throttle pattern:
  ```
  let ticking = false;
  const onScroll = () => {
    if (!ticking) {
      requestAnimationFrame(() => {
        setIsScrolled(window.scrollY > threshold);
        ticking = false;
      });
      ticking = true;
    }
  };
  ```
- Call onScroll() once on mount to handle back-button mid-page loads
- addEventListener('scroll', onScroll, { passive: true })
- Cleanup: removeEventListener
- Export: `export function useScrolled(threshold = 10): boolean`
