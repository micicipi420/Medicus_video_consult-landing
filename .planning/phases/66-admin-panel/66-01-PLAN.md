**Filtering logic (useMemo):**
```typescript
const filtered = useMemo(() => {
  return submissions.filter((s) => {
    if (statusFilter !== 'all' && s.status !== statusFilter) return false;
    if (dateFrom) {
      const from = new Date(dateFrom);
      if (s.dateCreated < from) return false;
    }
    if (dateTo) {
      const to = new Date(dateTo);
      to.setHours(23, 59, 59, 999); // include the entire "to" day
      if (s.dateCreated > to) return false;
    }
    return true;
  });
}, [submissions, statusFilter, dateFrom, dateTo]);
```

**Filtered count:** Show "Показано: {filtered.length} из {submissions.length}" below the filter bar when filters are active (i.e., filtered.length !== submissions.length).
