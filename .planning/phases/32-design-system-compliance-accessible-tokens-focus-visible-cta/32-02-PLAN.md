  <files>index.html, online-consultations.html, treatment-abroad.html, checkup.html, contacts.html, 404.html</files>
  <action>
Process each of the 6 HTML files with these replacements. The order matters -- do CTA gradient first (most mechanical), then text colors (requires judgment).

**Replacement 1: CTA gradient (mechanical find-replace, per A11Y-04)**

In ALL 6 files, replace every occurrence of:
- `from-mu-blue to-mu-accent-blue` with `from-mu-cta-from to-mu-cta-to`

This affects ~77 CTA button gradient classes. It is a pure string replacement -- no judgment needed. Every `from-mu-blue to-mu-accent-blue` is a CTA gradient.

**Replacement 2: Hover text colors (mechanical find-replace, per A11Y-05)**

In ALL 6 files, replace:
- `hover:text-mu-blue` with `hover:text-mu-blue-text` (on links, ~88 occurrences)
- `group-hover:text-mu-blue` with `group-hover:text-mu-blue-text` (on card headings)

These are all on text elements (link hover states), so 100% should be replaced.

**Replacement 3: Readable text accent colors (requires judgment, per A11Y-05)**

For each file, identify and replace bright accent colors used on **readable text** only. DO NOT replace on SVG icons, bg-clip-text gradient text, or decorative elements.

Rules for identification:
- `text-mu-blue` on `<a>`, `<p>`, `<span>`, `<h1-h6>`, `<li>`, `<label>`, `<div>` containing visible text → replace with `text-mu-blue-text`
- `text-mu-blue` on `<svg>` elements → KEEP original (icon color)
- `text-mu-accent-teal` on `<span>` with number text (e.g., "43", "11") → replace with `text-mu-accent-teal-text`
- `text-mu-accent-orange` on `<span>` with number text (e.g., "15+", "10 000+") → replace with `text-mu-accent-orange-text`
- `text-mu-accent-blue` on `<span>`, `<p>`, `<h3>` with readable text → replace with `text-mu-accent-blue-text`
- `text-mu-green-600` on `<span>`, `<p>` with readable text → replace with `text-mu-green-text`
- `text-mu-green-600` on SVG checkmark icons → KEEP original

In every HTML file that has a contact form (index.html, online-consultations.html, treatment-abroad.html, checkup.html, contacts.html -- NOT 404.html which has no form), find all elements with class `form__field-error` or `form__error` and add `role="alert" aria-live="polite"` attributes.

There are approximately 50 such elements across the 5 pages with forms (roughly 9-10 per page).

The DESIGN-SYSTEM.md specifies Glass-5 (form contact) as `bg-white/70`. Find form wrapper containers and update from `bg-white/60` to `bg-white/70`. Only change the **form container** divs, not other Glass-4 card elements.

Specific elements to change:
- checkup.html line ~685: `form-wrapper bg-white/60` → `form-wrapper bg-white/70`
- online-consultations.html: the form container div with `bg-white/60 backdrop-blur-3xl rounded-[3rem]` that wraps the consultation form → change to `bg-white/70`

- Service cards (Glass-4 = bg-white/60, correct as-is)
