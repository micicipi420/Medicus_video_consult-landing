<task type="auto">
  <name>Task 2: Add global focus-visible and prefers-reduced-motion CSS rules</name>
  <files>src/styles/theme.css</files>
  <action>
In src/styles/theme.css, add two rules inside the existing `@layer base { ... }` block.

**1. Focus-visible rule** (per A11Y-03 -- add after the `body { ... }` rule, before the heading rules):

```css
/* Focus-visible: keyboard navigation ring for all interactive elements */
a:focus-visible,
button:focus-visible,
input:focus-visible,
select:focus-visible,
textarea:focus-visible,
[role="button"]:focus-visible,
[tabindex]:focus-visible {
  outline: none;
  box-shadow: 0 0 0 2px white, 0 0 0 4px var(--mu-blue-text);
}
```

Use box-shadow instead of Tailwind ring utilities because this is a global CSS rule (not utility classes). The `0 0 0 2px white` provides the ring-offset-2 effect, `0 0 0 4px var(--mu-blue-text)` provides the ring-2 in brand color. This approach: (a) requires zero HTML changes across all 6 pages, (b) matches the DESIGN-SYSTEM.md spec of focus-visible:ring-2 focus-visible:ring-mu-blue-text focus-visible:ring-offset-2, (c) uses the new --mu-blue-text token.

**2. prefers-reduced-motion rule** (per A11Y-07 -- add after the `@layer base` block, at the end of the file):

```css
/* Accessibility: disable animations for users who prefer reduced motion */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

This matches the DESIGN-SYSTEM.md spec exactly. Place it OUTSIDE @layer base (at the top level of the file) so it applies universally.
