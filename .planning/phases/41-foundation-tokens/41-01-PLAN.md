```css
  --squircle-mask-lg:   url("data:image/svg+xml,...");
  --squircle-mask-xl:   url("data:image/svg+xml,...");

  --liquid-bg: rgba(255, 255, 255, 0.18);

  --liquid-blur-md: 24px;

  --liquid-border-top: rgba(255, 255, 255, 0.9);
  --liquid-border-bottom: rgba(255, 255, 255, 0.35);

  /* Motion tokens */

  --ease-liquid-out: cubic-bezier(0.16, 1, 0.3, 1);
  --dur-press: 120ms;
  --dur-hover: 280ms;
  --dur-sheet: 400ms;
  --dur-reveal: 600ms;
```

**For squircle SVG data-URIs:** Generate 4 superellipse SVG paths using the parametric Lame curve formula with n=5, 64 points per quadrant, in a 100x100 viewBox with preserveAspectRatio="none". The 4 variants differ by the inset/rounding applied:
- `md`: 12% corner inset (moderate rounding, for cards)
- `lg`: 18% corner inset (larger rounding, for hero cards)
- `xl`: 25% corner inset (very rounded, for large panels)
- `full`: border-radius: 9999px approach -- per Research open question #3, `full` does NOT need an SVG mask because 50% border-radius already produces a circle; store a placeholder comment: `/* full: use border-radius: 50% -- no mask needed */` and set the token value to `none`

SVG encoding rules for CSS url() values:
- Use `url("data:image/svg+xml,<svg ...>...</svg>")` format
- Replace `#` with `%23` in any color values
- Use single quotes inside SVG attributes (e.g., fill='white')
- Keep SVG on single line (no line breaks within the data-URI string)
- The SVG structure: `<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 100 100' preserveAspectRatio='none'><path fill='white' d='...' /></svg>`
