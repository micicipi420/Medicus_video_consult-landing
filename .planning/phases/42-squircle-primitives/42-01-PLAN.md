**1. Create src/styles/squircles.css with the following structure:**

File header comment documenting: purpose, three-tier degradation chain (Tier 1: Chrome 139+ native corner-shape, Tier 2: mask-image SVG production default, Tier 3: border-radius fallback), shadow-wrap pattern idiom with HTML example.

Shadow-wrap documentation in the header comment MUST include (per SQUIRCLE-04):
- Explanation: mask-image clips box-shadow, so outer shadows need a wrapper element
- Pattern: outer wrapper carries box-shadow + matching border-radius, inner element carries squircle mask
- HTML example showing card wrap and button wrap
- Note: inset shadows are safe inside mask (no wrap needed)
- Note: elements with no shadow need no wrap (badges, chips)
- Anti-pattern: NEVER apply box-shadow AND mask-image to the same element

**2. Four utility classes (per SQUIRCLE-01):**

```css
.squircle-md {
  border-radius: 16px;
  -webkit-mask-image: var(--squircle-mask-md);
          mask-image: var(--squircle-mask-md);
  -webkit-mask-size: 100% 100%;
          mask-size: 100% 100%;
}

.squircle-lg {
  border-radius: 24px;
  -webkit-mask-image: var(--squircle-mask-lg);
          mask-image: var(--squircle-mask-lg);
  -webkit-mask-size: 100% 100%;
          mask-size: 100% 100%;
}

.squircle-xl {
  border-radius: 40px;
  -webkit-mask-image: var(--squircle-mask-xl);
          mask-image: var(--squircle-mask-xl);
  -webkit-mask-size: 100% 100%;
          mask-size: 100% 100%;
}

.squircle-full {
  border-radius: 9999px;
  /* No mask needed -- at full radius, squircle = circle.
     --squircle-mask-full is 'none' in theme.css. */
}
```

Every mask-image MUST be paired with -webkit-mask-image prefix (Safari compat).
Every mask-size MUST be paired with -webkit-mask-size prefix.
.squircle-full MUST NOT have mask-image (it uses border-radius only -- per Research Pitfall 4).

**3. Progressive enhancement block (per SQUIRCLE-02):**

```css
@supports (corner-shape: superellipse(2)) {
  .squircle-md,
  .squircle-lg,
  .squircle-xl,
  .squircle-full {
    -webkit-mask-image: none;
            mask-image: none;
    corner-shape: superellipse(2);
  }
}
```

Use `superellipse(2)` specifically (not `squircle` keyword) -- per CONTEXT.md locked decision.
The @supports block strips the mask and applies native rendering for Chrome 139+.
