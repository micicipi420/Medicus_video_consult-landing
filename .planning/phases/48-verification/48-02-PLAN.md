**VERIFY-04: Reduced Motion Audit**

Step 1 — Verify CSS reduced-motion guards exist in BOTH files:
- theme.css: blanket guard zeroing animation-duration/transition-duration and motion tokens
- liquid-glass.css: glass-specific guard reducing blur to 8px and hiding shimmer

Step 2 — Verify completeness of liquid-glass.css reduced-motion block:
- .liquid-regular: backdrop-filter reduced to blur(8px) -- CHECK
- .liquid-card: backdrop-filter reduced to blur(8px) -- CHECK
- .liquid-btn-secondary: backdrop-filter reduced to blur(8px) -- CHECK
- .stats-glass: backdrop-filter reduced to blur(8px) -- CHECK
- .shimmer-sweep::before: display: none -- CHECK
- MISSING CHECK: .liquid-btn-primary should NOT have backdrop-filter reduced (it uses gradient, not glass)
- MISSING CHECK: .scroll-fade-top / .scroll-fade-bottom mask-image should be preserved (static, no animation)

Step 3 — Verify refraction is disabled under reduced-motion:
- The refraction effect (html[data-refract="true"]) adds SVG filter to backdrop-filter
- Under reduced-motion, liquid-glass.css overrides backdrop-filter to blur(8px) only
- QUESTION: Does the reduced-motion rule have enough specificity to override html[data-refract="true"] .liquid-regular?
- Check specificity: `@media (prefers-reduced-motion: reduce) { .liquid-regular }` (0,1,0) vs `html[data-refract="true"] .liquid-regular` (0,1,1)
- If refraction selector wins, the reduced-motion guard is BYPASSED for refraction users. This is a potential bug.

Step 4 — Verify JS respects reduced-motion:
- Grep js/main.js for all animation-related functions
- Confirm each one checks prefers-reduced-motion before running
- Specifically check: scroll-reveal animations, counter animations, any Motion library calls

Step 5 — Verify print stylesheet in liquid-glass.css:
- All glass classes get backdrop-filter: none, background: white, border: 1px solid #ccc
- Shimmer hidden
- Scroll-fade masks removed
- Check: Are squircle mask-images handled in print? (mask-image hides content in print if not addressed)

Step 6 — Grep all 6 pages for any inline animation/transition styles that bypass the reduced-motion media query. Check for:
- style="transition:..." on any element
- style="animation:..." on any element
- Inline CSS in style blocks with transition/animation without @media (prefers-reduced-motion) guard

**VERIFY-03: Budget Android FPS Assessment**

```css
@media (prefers-reduced-motion: reduce) {
  .liquid-regular,
  .liquid-card,
  .liquid-btn-secondary,
  .stats-glass,
  html[data-refract="true"] .liquid-regular,

    backdrop-filter: blur(8px);
    -webkit-backdrop-filter: blur(8px);

}
```
This ensures reduced-motion overrides refraction regardless of specificity.
