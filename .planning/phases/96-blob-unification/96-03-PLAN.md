  Create a Playwright e2e spec scoped to the mobile-375 project that
  asserts the same &lt;= 8px ceiling on max angular separation during slow
  Lissajous ambient drift.

  Spec:
    import { test, expect } from '@playwright/test';

    // Force Playwright to emulate a coarse-pointer / no-hover touch device so
    // matchMedia('(pointer: coarse) and (hover: none)') matches and resolveMode
    // returns 'ambient'.
    test.use({ hasTouch: true, isMobile: true });

    test.describe('blob mobile ambient correlated motion (BR-03)', () => {
      test('max angular separation during 5s Lissajous drift stays <= 8px', async ({ page }) => {
        await page.goto('/');

        // Wait for engine to enter ambient mode (coarse-pointer chain).
        await page.waitForFunction(
          () => (window as any).__blobDebug?.mode === 'ambient',
          { timeout: 5000 },
        );

        // Reset the rolling max so the previous (zero-motion) initialization
        // doesn't pollute the sample.
        await page.evaluate(() => (window as any).__blobDebug.resetMaxSeparation());

        // Sample over 5 seconds — Lissajous periods are 17s + 23s, 5s gives a
        // representative arc.
        await page.waitForTimeout(5000);

        const maxSep = await page.evaluate(() => (window as any).__blobDebug.maxAngularSeparation as number);
        expect(maxSep).toBeLessThanOrEqual(8);
      });
    });

  Run only against project 'mobile-375'. Do NOT run on 'desktop' (cursor
  mode would dominate; the assertion is mobile-specific).
  </action>
