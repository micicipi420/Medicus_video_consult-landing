<task type="auto">
  <name>Task 2: Add will-change hygiene to animated glass selectors</name>
  <files>src/styles/liquid-glass.css, css/styles.css</files>
  <action>
In src/styles/liquid-glass.css, add targeted will-change declarations to ONLY the selectors that animate. Per PERF-02: will-change must be absent from all static/base glass selectors.

1. **Section 16 -- Interaction hover states** (around line 900): Add `will-change: filter, transform;` to the existing HOVER rule block:
```css
.liquid-regular:hover,
.liquid-card:hover,
.liquid-nav:hover,
.liquid-clear:hover,
.liquid-fluted:hover,
.stats-glass:hover {
  filter: brightness(1.04);
  transition: filter var(--dur-hover) var(--ease-liquid);
  will-change: filter, transform;
}
```
This promotes the composite layer only when the user hovers, not permanently.

2. **Section 16 -- Interaction active states** (around line 911): Add `will-change: filter, transform;` to the active rule block:
```css
.liquid-regular:active,
.liquid-card:active,
...
{
  filter: brightness(0.96);
  transform: scale(0.985);
  transition: filter var(--dur-press) ...;
  will-change: filter, transform;
}
```

3. **Section 8 -- Glint animation on .liquid-card::before** (around line 438): Add `will-change: background-position;` to the `.liquid-card::before` rule since it has `animation: glint 6s linear infinite`:
```css
.liquid-card::before {
  ...
  animation: glint 6s linear infinite;
  will-change: background-position;
  ...
}
```

4. **Section 5 -- Shimmer sweep hover** (around line 388): Add `will-change: transform;` to `.shimmer-sweep:hover::before`:
```css
.shimmer-sweep:hover::before {
  transform: translateX(100%);
  will-change: transform;
}
```

5. **Section 3 -- Button hover states**: Add `will-change: filter, transform;` to `.liquid-btn-primary:hover` and `.liquid-btn-secondary:hover`.

6. **DO NOT add will-change to**:
   - Base selectors (.liquid-regular, .liquid-card, etc.) -- static
   - Print, reduced-motion, or reduced-transparency media query blocks
   - The base transition declaration in Section 16 (the one without :hover/:active)
   - Any selector containing `will-change: backdrop-filter` -- this is prohibited per codebase convention

7. Add a comment at the top of Section 16: `/* will-change applied on :hover/:active only -- never on base selectors (PERF-02) */`

After changes: run `make build` to rebuild css/styles.css.
