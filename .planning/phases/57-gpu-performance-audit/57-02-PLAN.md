<objective>
Implement viewport-aware backdrop-filter budget enforcement so no more than 6 glass elements have active backdrop-filter at any scroll position.

Purpose: Glass effects are the most expensive GPU operation on the page. On dense pages like index.html (58+ glass elements), scrolling through sections with 8-10 simultaneous glass elements causes paint/composite jank. A viewport budget ensures only the 6 most important glass elements blur at any time.

Output: IntersectionObserver-based glass budget system in main.js, CSS idle class in liquid-glass.css, zero viewport positions exceeding the 6-element limit.
</objective>

**Part A -- CSS: Add .glass-idle class to src/styles/liquid-glass.css**

Add a new Section 18 after the existing Section 17 (specular highlight), before the closing end of the file:

```css
/* ================================================
   Section 18 -- Viewport budget (PERF-01)
   Glass elements outside the viewport or exceeding
   the 6-element budget get .glass-idle added by JS.
   This disables backdrop-filter (replacing it with
   an opaque background approximation) to reduce
   GPU composite layer count.
   The class is removed when the element scrolls back
   into the viewport and budget allows.
   Priority: header > nav > cards/regular > buttons.
   ================================================ */

.glass-idle {
  backdrop-filter: none !important;
  -webkit-backdrop-filter: none !important;
}

/* Idle elements get an opaque background approximation
   so they don't become fully transparent. Light/dark
   mode handled via separate selectors. */
.glass-idle.liquid-regular,
.glass-idle.liquid-card,
.glass-idle.liquid-btn-secondary,
.glass-idle.stats-glass,
.glass-idle.liquid-fluted {
  background: rgba(255, 255, 255, 0.75) !important;
}

.glass-idle.liquid-nav {
  background: rgba(255, 255, 255, 0.60) !important;
}

.glass-idle.liquid-clear {
```

**Part B -- JavaScript: Add initGlassBudget() to js/main.js**

Add a new function `initGlassBudget()` in the IIFE, placed after `initMouseSpecular()` and before `initStickyHeader()`.

Implementation requirements:

1. **Budget constant**: `var GLASS_BUDGET = 6;`

2. **Priority system**: Elements have priority tiers determining which get downgraded first when budget is exceeded:
   - Priority 1 (never downgraded): Elements matching `.header .liquid-regular` (the sticky header itself) and `.liquid-header-backdrop`
   - Priority 2 (high): `.liquid-nav`, `.stats-glass`
   - Priority 3 (medium): `.liquid-card`, `.liquid-regular` (not inside header)
   - Priority 4 (low, downgraded first): `.liquid-btn-secondary`, `.liquid-clear`, `.liquid-fluted`

3. **Selector**: Use the same glass selector as mouse specular, but also include `.liquid-btn-secondary` and `.liquid-header-backdrop`:
   ```javascript
   var GLASS_SELECTOR = '.liquid-card, .liquid-regular, .liquid-nav, .liquid-clear, .liquid-fluted, .stats-glass, .liquid-btn-secondary, .liquid-header-backdrop';
   ```

4. **State tracking**: Maintain a Set of currently-visible glass elements (`visibleSet`).

5. **IntersectionObserver setup**:
   ```javascript
   var observer = new IntersectionObserver(function(entries) {
     entries.forEach(function(entry) {
       if (entry.isIntersecting) {
         visibleSet.add(entry.target);
       } else {
         visibleSet.delete(entry.target);
         entry.target.classList.add('glass-idle');
       }
     });
     enforceBudget();
   }, { threshold: 0 });
   ```

6. **enforceBudget() function**:
   - Convert visibleSet to array
   - Sort by priority (lower number = higher priority = kept active)
   - For priority assignment, use a helper `getPriority(el)`:
     - If el matches `.header .liquid-regular` or el matches `.liquid-header-backdrop` -> return 1
     - If el matches `.liquid-nav` or `.stats-glass` -> return 2
     - If el matches `.liquid-card` or (el matches `.liquid-regular` and NOT inside `.header`) -> return 3
     - Else -> return 4
   - Within same priority, preserve DOM order (which is the natural querySelectorAll order)
   - First GLASS_BUDGET elements: remove `.glass-idle`
   - Remaining elements: add `.glass-idle`

7. **Observer attachment**: Query all glass elements on the page and observe each:
   ```javascript
   var allGlass = document.querySelectorAll(GLASS_SELECTOR);
   allGlass.forEach(function(el) { observer.observe(el); });
   ```

8. **SPA router support**: Add `initGlassBudget` to `reinitPageContent()` so it re-observes new page content. The function should disconnect the previous observer before creating a new one (store observer reference in closure).

9. **Reduced motion/transparency**: Do NOT skip budget enforcement for reduced-motion users. Budget enforcement reduces GPU load which benefits ALL users, especially those on low-power devices. (Reduced motion/transparency already disable backdrop-filter via media queries, so .glass-idle is a no-op for them.)

10. **Update initAll()**: Call `initGlassBudget()` after `initMouseSpecular()`.

11. **Update reinitPageContent()**: Call `initGlassBudget()` in the reinit list.

12. **Expose on window.MU**: `window.MU.initGlassBudget = initGlassBudget;`

After changes: run `make build` to rebuild css/styles.css.
