**Step 1: Add color-scheme declaration.**

At the very top of the `:root` block (after the opening `{`), before the `--font-size` declaration, add:

```css
  /* Enable light-dark() function (Phase 73 / TOK-02) */
  color-scheme: light dark;
```

This tells the browser which color schemes the page supports, which is required for `light-dark()` to function correctly. The `.dark` class override already exists in the design system -- adding `color-scheme` does not conflict because `light-dark()` reads the computed color-scheme of the element.

**IMPORTANT:** Also add a `.dark` override for color-scheme so that when `.dark` class is applied, light-dark() picks the dark values:

In the `.dark` block, at the very top (after the opening `{`), add:
```css
  color-scheme: dark;
```

**Step 2: Identify which tokens are eligible for light-dark().**

ELIGIBLE (entire value is a single `<color>`):
- `--liquid-bg` (light: color-mix...42%, dark: color-mix...45%)
- `--liquid-border-top` (light: color-mix...tint 70%, dark: color-mix...light 25%)
- `--liquid-border-bottom` (light: color-mix...sub 25%, dark: color-mix...dim 40%)
- `--liquid-nav-bg` (light: color-mix...light 28%, dark: color-mix...dark 30%)
- `--liquid-clear-bg` (light: color-mix...light 18%, dark: color-mix...dark 22%)
- `--liquid-clear-dim` (light: color-mix...dim 12%, dark: color-mix...dim 30%)
- `--liquid-fluted-stripe-color` (light: color-mix...light 10%, dark: color-mix...light 6%)

NOT ELIGIBLE (compound values containing non-color data):
- `--liquid-shadow-outer` (contains "0 16px 40px " prefix -- not a pure color)
- `--liquid-shadow-inset-top` (contains "inset 0 1px 0 " prefix)
- `--liquid-shadow-inset-bottom` (contains "inset 0 -1px 0 " prefix)
- `--liquid-clear-shadow-outer` (contains "0 8px 32px " prefix)
- `--liquid-nav-shadow-outer` (value is "none" in both modes -- already same, no need for light-dark)

Also NOT modifying with light-dark():
- `--liquid-blur-*` (px values, not colors)
- `--liquid-saturate`, `--liquid-brightness` (percentage values, not colors)
- `--liquid-nav-blur`, `--liquid-clear-blur` (px values)
- `--liquid-fluted-stripe-width`, `--liquid-fluted-stripe-gap` (px values, same in both modes)

**Step 3: Rewrite the 7 eligible :root tokens using light-dark().**

Replace each eligible token in `:root` with a light-dark() expression that embeds both the light and dark color-mix values:

```css
  --liquid-bg: light-dark(
    color-mix(in oklch, var(--glass-base-light) 42%, transparent),
    color-mix(in oklch, var(--glass-base-dark) 45%, transparent)
  );
  --liquid-border-top: light-dark(
    color-mix(in oklch, var(--glass-border-tint) 70%, transparent),
    color-mix(in oklch, var(--glass-base-light) 25%, transparent)
  );
  --liquid-border-bottom: light-dark(
    color-mix(in oklch, var(--glass-border-sub) 25%, transparent),
    color-mix(in oklch, var(--glass-dim-base) 40%, transparent)
  );
  --liquid-nav-bg: light-dark(
    color-mix(in oklch, var(--glass-base-light) 28%, transparent),
    color-mix(in oklch, var(--glass-base-dark) 30%, transparent)
  );
  --liquid-clear-bg: light-dark(
    color-mix(in oklch, var(--glass-base-light) 18%, transparent),
    color-mix(in oklch, var(--glass-base-dark) 22%, transparent)
  );
  --liquid-clear-dim: light-dark(
    color-mix(in oklch, var(--glass-dim-base) 12%, transparent),
    color-mix(in oklch, var(--glass-dim-base) 30%, transparent)
  );
  --liquid-fluted-stripe-color: light-dark(
    color-mix(in oklch, var(--glass-base-light) 10%, transparent),
    color-mix(in oklch, var(--glass-base-light) 6%, transparent)
  );
```

**Step 5: Update the .header--scrolled overrides.**

The `.header--scrolled` block in @layer components currently has color-mix values for both light and dark. Consolidate:

For light-dark() to respond to `.dark` class, the `.dark` block MUST set `color-scheme: dark`. This is why Step 1 adds that declaration.
