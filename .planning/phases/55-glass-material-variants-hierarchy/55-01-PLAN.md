**Step B: Add .liquid-nav class to liquid-glass.css**

Insert a new Section 1.1 AFTER Section 1 (after line 89, after `.liquid-regular` closing brace). Use this exact pattern:

```css
/* ================================================
   Section 1.1 -- Nav-weight material (GLAS-03 Level 1)
   Lightest glass: minimal blur, highest transparency,
   no outer shadow. For navigation bars, toolbars.
   Formalizes the "navigation weight" from the glass
   hierarchy: nav < regular < clear.
   ================================================ */

.liquid-nav {
  isolation: isolate;
  position: relative;
  background:
    linear-gradient(
      to bottom,
      var(--liquid-nav-bg),
      var(--liquid-nav-bg)
    ),
    linear-gradient(
      to bottom,
      hsla(var(--liquid-tint-h), var(--liquid-tint-s), var(--liquid-tint-l), var(--liquid-tint-a)),
      hsla(var(--liquid-tint-h), var(--liquid-tint-s), var(--liquid-tint-l), var(--liquid-tint-a))
    );
  backdrop-filter: blur(var(--liquid-nav-blur)) saturate(var(--liquid-saturate)) brightness(var(--liquid-brightness));
  -webkit-backdrop-filter: blur(16px) saturate(180%) brightness(108%);
  -webkit-backdrop-filter: blur(var(--liquid-nav-blur)) saturate(var(--liquid-saturate)) brightness(var(--liquid-brightness));
  box-shadow:
    var(--liquid-shadow-inset-top),
    var(--liquid-shadow-inset-bottom);
  /* No outer shadow -- nav floats light */
}
```

```css
/* ================================================
   Section 1.2 -- Clear-weight material (GLAS-01 / GLAS-03 Level 3)
   Highest transparency + dimming backdrop layer.

    ),
    linear-gradient(
      to bottom,
      hsla(var(--liquid-tint-h), var(--liquid-tint-s), var(--liquid-tint-l), var(--liquid-tint-a)),
      hsla(var(--liquid-tint-h), var(--liquid-tint-s), var(--liquid-tint-l), var(--liquid-tint-a))
    );
  backdrop-filter: blur(var(--liquid-clear-blur)) saturate(var(--liquid-saturate)) brightness(var(--liquid-brightness));
  -webkit-backdrop-filter: blur(20px) saturate(180%) brightness(108%);
  -webkit-backdrop-filter: blur(var(--liquid-clear-blur)) saturate(var(--liquid-saturate)) brightness(var(--liquid-brightness));
  box-shadow:
    var(--liquid-shadow-inset-top),
    var(--liquid-shadow-inset-bottom),
    var(--liquid-clear-shadow-outer);
}

/* Dimming layer -- sits behind glass content, darkens the backdrop area */
.liquid-clear::after {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: inherit;
  background: var(--liquid-clear-dim);
  pointer-events: none;
  z-index: -1;
}
```

**Step D: Add .liquid-fluted class to liquid-glass.css**

Insert a new Section 1.3 AFTER Section 1.2:

```css
/* ================================================
   Section 1.3 -- Fluted material (GLAS-02)
   Regular-weight glass with vertical ribbed streaks
   overlaid via repeating-linear-gradient. Produces
   the "fluted glass" texture (iOS-inspired ribbing).
   Uses ::after for the streak layer so it composites
   above the backdrop-filter blur.
   ================================================ */

.liquid-fluted {
  isolation: isolate;
  position: relative;
  background:
    linear-gradient(
      to bottom,
      var(--liquid-bg),
      var(--liquid-bg)
    ),
    linear-gradient(
      to bottom,
      hsla(var(--liquid-tint-h), var(--liquid-tint-s), var(--liquid-tint-l), var(--liquid-tint-a)),
      hsla(var(--liquid-tint-h), var(--liquid-tint-s), var(--liquid-tint-l), var(--liquid-tint-a))
    );
  backdrop-filter: blur(var(--liquid-blur-md)) saturate(var(--liquid-saturate)) brightness(var(--liquid-brightness));
  -webkit-backdrop-filter: blur(24px) saturate(180%) brightness(108%);
  -webkit-backdrop-filter: blur(var(--liquid-blur-md)) saturate(var(--liquid-saturate)) brightness(var(--liquid-brightness));
  box-shadow:
    var(--liquid-shadow-inset-top),
    var(--liquid-shadow-inset-bottom),
    var(--liquid-shadow-outer);
}

/* Vertical ribbed streaks -- composites above the blurred backdrop */
.liquid-fluted::after {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: inherit;
  background: repeating-linear-gradient(
    90deg,
    var(--liquid-fluted-stripe-color) 0px,
    var(--liquid-fluted-stripe-color) var(--liquid-fluted-stripe-width),
    transparent var(--liquid-fluted-stripe-width),
    transparent calc(var(--liquid-fluted-stripe-width) + var(--liquid-fluted-stripe-gap))
  );
  pointer-events: none;
  z-index: 1;
}
```
