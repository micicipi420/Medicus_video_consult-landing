Create `next/src/hooks/use-specular-highlight.ts` exporting a `useSpecularHighlight` hook.

**Signature:**
```typescript
export function useSpecularHighlight(ref: React.RefObject<HTMLElement | null>): void
```

**Behavior:**
1. On mount, check `window.matchMedia('(pointer: fine)')` -- if false (touch device), return early (no tracking). This is a one-time check, not reactive.
2. Check `window.matchMedia('(prefers-reduced-motion: reduce)')` -- if true, return early (CSS Section 13 already freezes specular at 30%/0%). This is also a one-time mount check.
3. Attach a `pointermove` event listener to the `ref.current` element.
4. On each pointermove event:
   - Get element bounds via `getBoundingClientRect()`
   - Calculate cursor position as percentage of element dimensions:
     - `mouseX = ((event.clientX - rect.left) / rect.width * 100)`
     - `mouseY = ((event.clientY - rect.top) / rect.height * 100)`
   - Set CSS custom properties on the element:
     - `element.style.setProperty('--mouse-x', mouseX + '%')`
     - `element.style.setProperty('--mouse-y', mouseY + '%')`
5. On `pointerleave`, reset to default position:
   - `element.style.removeProperty('--mouse-x')`
   - `element.style.removeProperty('--mouse-y')`
   (This makes the CSS fallback `var(--mouse-x, 30%)` kick in, returning to the static position.)
6. Use `requestAnimationFrame` throttling: store the latest event in a ref, schedule rAF only if not already pending. This prevents layout thrashing from rapid pointermove events.
7. Clean up event listeners and cancel any pending rAF in the useEffect cleanup function.
8. Mark the hook as `'use client'` (needed because it uses browser APIs).

**Do NOT:**
- Use Framer Motion for this -- raw DOM event listeners are correct for CSS custom property updates (Framer Motion's event system does not provide element-relative coordinates efficiently).
- Use `mousemove` -- use `pointermove` (works for both mouse and stylus; ignored on touch via the pointer:fine gate).
- Apply will-change -- the specular pseudo-element is not promoted to its own layer and should not be (PERF-02 constraint from liquid-glass.css).

**1. Create `next/src/components/motion/GlassInteraction.tsx`:**

```typescript
'use client';

import { useRef } from 'react';
import { useSpecularHighlight } from '@/hooks/use-specular-highlight';

interface GlassInteractionProps {
  children: React.ReactNode;
  className?: string;
  as?: 'div' | 'article' | 'section';
}

export function GlassInteraction({
  children,
  className,
  as: Tag = 'div',
}: GlassInteractionProps) {
  const ref = useRef<HTMLElement>(null);
  useSpecularHighlight(ref);

  return (
    <Tag ref={ref as React.RefObject<any>} className={className}>
      {children}
    </Tag>
  );
}
```

Key details:
- `'use client'` directive (uses ref + hook with browser APIs)
- Polymorphic `as` prop defaulting to `div` (glass elements may be `article`, `section`, etc.)
- Passes ref to hook for event listener attachment
- Transparent wrapper: passes through className and children
- No Framer Motion dependency (not needed -- hover/press states are CSS-only via liquid-glass.css Section 16)
