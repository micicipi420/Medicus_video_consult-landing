Audit every new rule added in Phase 76 against the `prefers-reduced-motion: reduce` requirement:

**Audit results:**
1. `.card` transition upgrade (plan 01, task 1) — transform added. The global `*` at line 208 sets `transition-duration: 0.01ms !important` which zeroes it. BUT `transform` on hover is not a transition — it's a transform value applied when hovered. The `transition-duration: 0.01ms` makes it instantaneous (not zero motion). The existing block at line 1666 adds `.card:hover { transform: none }` — confirm plan 01 added this, if not, add it here.
2. `.mu-spin` animation (plan 01, task 2) — the global `*` override sets `animation-duration: 0.01ms !important` — this makes the spin near-instant (visual artifact). Plan 01 added `animation: none` for `.lead-form__submit.is-loading::after` under `prefers-reduced-motion`. Confirm this exists.
3. `filter: brightness(1.06)` on nav hover (plan 02, task 1) — filter is a paint operation, not a transition. It applies instantly on hover — no duration. No reduced-motion concern.
4. `text-shadow` additions (plan 02, task 1) — static styles, not animated. No concern.

Append at the END of the section 16 block in css/styles.css, AFTER all other section 16 rules:

```css
/* -- INT-04: prefers-reduced-motion — phase 76 complete coverage -- */
@media (prefers-reduced-motion: reduce) {
  /* Card hover: no lift (plan 01 may have already added this — if so, this is a no-op duplicate) */
  .card:hover {
    transform: none;
  }

  /* Hub service: no lift in reduced-motion (referenced in existing block? add explicitly) */
  .hub-service:hover {
    transform: none;
  }

  /* Spinner: static ring (plan 01 added animation:none for ::after — belt-and-suspenders here) */
  .lead-form__submit.is-loading::after {
    animation: none;
  }

  /* Filter transitions on nav hover: filter is instantaneous (no transition-duration),
     so it fires instantly on hover. For users wanting zero motion, remove filter entirely. */
  .site-header__link:hover,
  .site-header__brand-link:hover,
  .sticky-bar__phone:hover {
    filter: none;
  }
}
```
