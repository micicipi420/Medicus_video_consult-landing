**js/main.js** — Add a new function `initStickyHeader` using ES5 IIFE pattern (per project convention):

```javascript
function initStickyHeader() {
  var header = document.getElementById('header');
  if (!header) return;

  window.addEventListener('scroll', function() {
    if (window.scrollY > 0) {
      header.classList.add('is-scrolled');
    } else {
      header.classList.remove('is-scrolled');
    }
  }, { passive: true });
}
```

Key details:
- Uses `{ passive: true }` for scroll performance
- Toggles `.is-scrolled` class based on `scrollY > 0`
- Targets `#header` by ID (already exists in HTML)
- ES5 function declaration (no arrow functions, per project convention)

Then add `initStickyHeader();` call inside the existing `initAll()` function, after the other init calls.

Do NOT modify any other existing functions. Do NOT add `requestAnimationFrame` or debounce — the classList toggle is cheap and passive listener is sufficient.
