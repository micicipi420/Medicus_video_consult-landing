### Task 1: Hardcoded hex strokes → currentColor + text color classes (TRTOVR-01, TRTOVR-02)

**Targets (verified count: 20 occurrences of `#38C6F4|#35B678|rgba(56,198,244|#047857`):**

Section 1 — SVG icons in feature cards (~lines 211-253): Multiple SVGs with `#38C6F4` stroke and `rgba(56,198,244,0.1)` fills, plus `#35B678` highlights.

Section 2 — Checkmark pattern (lines 748, 754, 760): 3 copies of `<path d="M4 10l4 4 8-8" stroke="#047857">` (emerald-700, different from mu palette).

**Strategy:**

For each SVG element:
1. Wrap or set text color class on the parent container: `text-mu-accent-blue` (for #38C6F4 family) or `text-mu-green-600` (for #35B678 family) or `text-mu-green-600` (for #047857 replacement).
2. Replace all `stroke="#38C6F4"` → `stroke="currentColor"` within that SVG.
3. Replace all `stroke="#35B678"` → use a second color via `class` on the specific `<path>` element, OR accept currentColor from parent if the dual-color pattern isn't critical.
4. Replace `fill="rgba(56,198,244,0.1)"` → `fill="color-mix(in oklch, var(--mu-accent-blue) 10%, transparent)"` (valid Tailwind v4 pattern).
5. Replace `stroke="#047857"` → `stroke="currentColor"` with `text-mu-green-600` class on the parent.

**Acceptance:** `grep -cE '#(38C6F4|35B678|047857)|rgba\(56,198,244' treatment-abroad.html` returns 0.

**Commit:** `refactor(34): treatment-abroad hardcoded hex → currentColor tokens (TRTOVR-01, TRTOVR-02)`
