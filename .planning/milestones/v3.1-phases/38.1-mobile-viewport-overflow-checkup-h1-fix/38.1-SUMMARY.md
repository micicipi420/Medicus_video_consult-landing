## Key insights (worth remembering)

1. **`overflow: clip` vs `overflow: hidden`** — `clip` is the correct primitive when you want to prevent scroll without creating a block formatting context or breaking `position: sticky` descendants. `overflow: hidden` on body does NOT propagate to `<html>` reliably; `overflow-x: clip` on `<html>` is the true safety net.

2. **`bg-clip-text` + `&nbsp;` chain is a mobile footgun.** A single gradient span containing an nbsp-bound cross-language phrase (Cyrillic + Latin brand names) becomes an unbreakable token that's wider than mobile viewports at display font sizes. Fix: split the span at natural break points AND unbind internal nbsp.

3. **`&nbsp;` is for subject+verb pairs and orphan prevention, NOT for list-item binding.** The country-card bug was `University&nbsp;Clinic&nbsp;of&nbsp;Munich&nbsp;&middot;&nbsp;University&nbsp;Clinic...` — every word including separators bound into one 799px string. The fix keeps nbsp WITHIN multi-word clinic names but uses regular spaces around `&middot;` separators. Matches the feedback memory rules precisely.

4. **SVG `rx` takes a single length**, not CSS shorthand. `rx="0 0 3 3"` is invalid and silently ignored by browsers (producing square corners). The correct per-corner rounding primitive is a `<clipPath>` parent with the base rounding applied to it.

5. **Playwright Chromium caches CSS aggressively across navigations.** After a `./tailwindcss` rebuild, the in-session browser needs `link.href = 'css/styles.css?t=' + Date.now()` to pick up changes. This is a Playwright-specific dev-loop concern, not a production issue.
