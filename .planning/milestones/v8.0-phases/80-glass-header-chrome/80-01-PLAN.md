## Task 1 — HeaderClient: scoped transition declaration

**File:** `next/src/components/layout/HeaderClient.tsx`

Replace the broad `transition-all duration-500` with a scoped property list that declares only what actually changes between scroll states. This avoids forcing the browser to track every CSS property and keeps repaints surgical.

**Change:**

```diff
- 'fixed z-50 transition-all duration-500 top-4 left-4 right-4 mx-auto max-w-7xl',
+ 'fixed z-50 transition-[padding,background-color,box-shadow,backdrop-filter] duration-300 top-4 left-4 right-4 mx-auto max-w-7xl',
```

**Done when:**
- `grep "transition-\[padding,background-color,box-shadow,backdrop-filter\]" next/src/components/layout/HeaderClient.tsx` matches once
- `grep "transition-all" next/src/components/layout/HeaderClient.tsx` returns no matches

## Task 2 — MobileMenu: HIG tap targets, ESC dismissal, tinted backdrop

**File:** `next/src/components/layout/MobileMenu.tsx`

1. **Add Escape key dismissal** inside the existing `useEffect`. Define `handleKeyDown` checking `event.key === 'Escape'` to call `setIsOpen(false)`. Attach via `window.addEventListener('keydown', handleKeyDown)` when open, remove in cleanup return.

2. **Toggle button:** Replace the existing `lg:hidden p-2 ... border border-white/50` class set with a 44×44 button: `flex h-11 w-11 items-center justify-center rounded-full border border-white/55 bg-white/55 text-mu-text-700 shadow-glass-sm backdrop-blur-xl backdrop-saturate-[180%] transition-[transform,background-color,box-shadow] duration-200 active:scale-[0.96] lg:hidden`.

3. **Backdrop:** Replace `bg-black/50` with `bg-mu-text-900/35 backdrop-blur-sm` for theme-aware soft tint.

4. **Glass nav panel:** Update `bg-white/60` → `bg-white/68` and reorder Tailwind classes to canonical order. Bump padding `p-6` → `p-5` to match user draft.

5. **Nav links (Link + a variants):** Replace the existing class string with `min-h-12 rounded-2xl px-4 py-3 font-semibold tracking-tight text-mu-text-900 transition-[background-color,color] duration-200 hover:bg-white/45`. Bumps weight from `font-medium` to `font-semibold` and adds the 48px tap-target floor.

6. **Phone link:** Replace existing class with `flex min-h-12 items-center gap-3 rounded-2xl px-4 py-3 transition-[background-color,color] duration-200 hover:bg-white/45`.

7. **Primary CTA:** Replace existing class with `mt-4 block min-h-14 w-full rounded-2xl bg-gradient-to-r from-mu-blue to-mu-accent-blue px-6 py-4 text-center font-extrabold tracking-tight text-white shadow-lg transition-[transform,box-shadow,filter] duration-200 active:scale-[0.96]`. 56px tap target with press feedback.

**Done when:**
- ESC key handler registered/cleaned in effect

- No `transition-all` or `transition-colors` remaining (scoped only)
