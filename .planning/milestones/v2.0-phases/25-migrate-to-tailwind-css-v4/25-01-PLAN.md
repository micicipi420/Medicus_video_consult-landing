  <action>
1. Download the Tailwind CSS v4 standalone CLI binary for macOS arm64:
   ```
   curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-macos-arm64
   chmod +x tailwindcss-macos-arm64
   mv tailwindcss-macos-arm64 tailwindcss
   ```

2. Create `src/styles/` directory.

3. Create `src/styles/fonts.css` — copy VERBATIM from `Redesign/src/styles/fonts.css`:
   The 2 @font-face blocks for SF Pro Display and SF Pro Rounded with local() sources.

4. Create `src/styles/theme.css` — copy VERBATIM from `Redesign/src/styles/theme.css`:
   - `@custom-variant dark` directive
   - `:root` block with all CSS custom properties (--mu-blue, --mu-green-*, --mu-text-*, --mu-accent-*, --background, --foreground, --border, --shadow-glass-*, --border-glass-*, --font-heading, --font-body, etc.)
   - `.dark` block with dark mode overrides
   - `@theme inline` block mapping all --color-* tokens
   - `@layer base` block with default typography styles

5. Create `src/styles/tailwind.css` — adapted from Redesign version. The Redesign file has:
   ```
   @import 'tailwindcss' source(none);
   @source '../**/*.{js,ts,jsx,tsx}';
   @import 'tw-animate-css';
   ```
   Adapt for HTML project:
   - Change `@source` to scan HTML files: `@source '../../*.html';`
   - REMOVE `@import 'tw-animate-css'` (this is an npm package not available without Node.js; animations are handled by js/animations.js with Motion standalone CDN)
   - Add imports for fonts.css and theme.css
   
   Final content:
   ```css
   @import './fonts.css';
   @import 'tailwindcss' source(none);
   @source '../../*.html';
   @import './theme.css';
   ```

6. Create `src/styles/index.css` — this was the React app's entry point importing all 3 files. For our standalone setup, it is NOT needed as an entry point (tailwind.css IS the entry point). However, if the Redesign's index.css contains any additional base styles beyond imports, copy those. The Redesign index.css is just 3 import lines — so we can skip creating this file or create it as a reference note.

7. Add `tailwindcss` binary and `css/tw-output.css` to `.gitignore` (the binary is ~50MB, should not be committed; compiled output is regenerated from source).

8. Test the build:
   ```
   ./tailwindcss -i src/styles/tailwind.css -o css/tw-output.css
   ```
   This should produce a CSS file without errors. It will be small initially since no HTML files use Tailwind classes yet.
  </action>
