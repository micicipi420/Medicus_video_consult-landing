### Architectural Finding: Dual-Layer CSS

Production HTML pages (`index.html`, `checkup.html`, `consultations.html`, `treatment-abroad.html`) load **only** `css/styles.css`. The files `src/styles/theme.css` and `src/styles/liquid-glass.css` serve the Next.js scaffold via Tailwind compilation.

This means Phase 73 token work (TOK-01, TOK-02) and Phase 74 glass accessibility (ACC-01 glass half, ACC-02, ACC-03) have zero runtime effect on the deployed static site. This is a known architectural property, not a regression.
