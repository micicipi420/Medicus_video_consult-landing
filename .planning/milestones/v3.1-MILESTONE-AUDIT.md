## Key Deviations & Findings

### Research-driven scope changes
1. **js/router.js discovery.** Research phase uncovered an existing 465-line SPA client router that already swaps `#page-content`, `#footer`, `#sticky-bar`. This fundamentally changed Phase 36's approach from runtime injection to build-time splice (which itself became 36b/deferred).
2. **Netlify deploy target (not nginx).** STACK.md's nginx SSI recommendation was invalidated mid-milestone. SUMMARY.md reconciled: build-time shell splice is the canonical approach, but required Netlify smoke-test (LAYOUT-12) pushed Phase 36b to v3.2.
3. **Dark-mode claim in PROJECT.md was stale.** No dark-mode toggle ships despite v1.4 claim. v3.1 avoided touching this; deferred to a focused dark-mode milestone.
4. **Tailwind v4 token key pattern.** Phase 38 smoke test (RHYTHM-03) caught that `--min-height-*` generates `min-h-*` utilities, NOT `--height-*` as the research draft assumed. Smoke test worked exactly as designed — prevented broken bulk migration.

### Scope absorptions
- **TRTOVR-04 (stat bar hierarchy rework)** was completed by Phase 33's AUDIT-05 work (emoji→SVG pivot resolved as "match index.html icon-less pattern"). Marked done without additional Phase 34 work.

### Bonus work (Rule 2 auto-fixes)

- **Phase 37:** Executor fetched 10 country flag SVGs (not 7 as planned) because the online-consultations country list had more countries. Total still within 14KB budget.

### Potential regressions to watch
