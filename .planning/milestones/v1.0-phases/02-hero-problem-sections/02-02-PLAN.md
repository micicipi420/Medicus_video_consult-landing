**css/styles.css — Add after the Hero styles in Section 7:**

```css
/* -- Problem -- */

.problem {
  background-color: var(--color-white);
}

.problem__heading {
  margin-bottom: var(--space-5);
}

.problem__items {
  max-width: 680px;
}

.problem__text {
  font-size: var(--font-size-lg);
  line-height: 1.7;
  color: var(--color-text-primary);
  margin-bottom: var(--space-4);
  padding-left: var(--space-3);
  border-left: 3px solid var(--color-primary);
}

.problem__text:last-child {
  margin-bottom: 0;
  font-weight: 600;
}
```

Design rationale:
- White background contrasts with Hero's light gray — natural visual separation without explicit dividers.
- Left border accent (3px solid brand blue) acts as subtle visual separator between paragraphs per CONTEXT.md discretion.
- Last paragraph ("Время идёт...") is bold — it's the emotional punch line.
- Max-width 680px keeps reading line length comfortable for the target audience (45+).
- font-size-lg (20px) for readability.
- No animations, no icons — per UX-06 calm confident tone.
