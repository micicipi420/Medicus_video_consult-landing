<task type="auto">
  <name>Task 1: Add preload tags and defer Motion CDN script on all pages</name>
  <files>index.html, online-consultations.html, treatment-abroad.html, checkup.html, contacts.html</files>
  <action>
    **Part A: Add preload tags to `<head>` of every page.**

    Insert these preload links BEFORE the `<link rel="stylesheet" href="css/styles.css">` line on each page.

    On ALL 5 pages, add:
    ```html
    <link rel="preload" href="css/styles.css" as="style">
    ```

    On **index.html** additionally add (hero images that load eagerly):
    ```html
    <link rel="preload" href="img/hero-doctor-portrait.webp" as="image" type="image/webp">
    ```

    On **online-consultations.html** additionally add:
    ```html
    <link rel="preload" href="img/hero-telemedicine-laptop.webp" as="image" type="image/webp">
    ```

    Note: Fonts are system fonts (SF Pro Display/Rounded loaded via `local()` in CSS), so there are no font files to preload.

    **Part B: Add `defer` attribute to Motion CDN script tag.**

    On these 4 pages that have the Motion CDN script, change the script tag:
    - index.html (line ~1070)
    - online-consultations.html (line ~853)
    - treatment-abroad.html (line ~971)
    - contacts.html (line ~327)

    FROM:
    ```html
    <script src="https://cdn.jsdelivr.net/npm/motion@12.23.24/dist/motion.js"></script>
    ```

    TO:
    ```html
    <script defer src="https://cdn.jsdelivr.net/npm/motion@12.23.24/dist/motion.js"></script>
    ```

    Note: checkup.html does NOT have a Motion CDN script tag -- skip it for Part B.

    Also add `defer` to `js/main.js` and `js/animations.js` script tags on the same 4 pages, since they depend on Motion being loaded and should also not block rendering:

    FROM:
    ```html
    <script src="js/main.js"></script>
    <script src="js/animations.js"></script>
    ```

    TO:
    ```html
    <script defer src="js/main.js"></script>
    <script defer src="js/animations.js"></script>
    ```

    On checkup.html (only has main.js, no animations.js, no motion):
    ```html
    <script defer src="js/main.js"></script>
    ```

    **Important:** `defer` maintains execution order, so motion.js will still execute before main.js and animations.js. This is correct behavior.
  </action>
  <verify>
    <automated>echo "=== Preload tags ===" && grep -c 'rel="preload"' index.html online-consultations.html treatment-abroad.html checkup.html contacts.html && echo "=== Defer on motion ===" && grep 'defer.*motion\|motion.*defer' index.html online-consultations.html treatment-abroad.html contacts.html && echo "=== Defer on main.js ===" && grep 'defer.*main\.js' index.html online-consultations.html treatment-abroad.html checkup.html contacts.html</automated>
  </verify>
